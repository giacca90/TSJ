# LANDING PAGE PARA EL TSJ WAKEPARK DE FRANCIA

## ¿QUE ES?

El TSJ es un parque acuático donde se hace wake con cable.

## ¿POR QUE?

Los dueños son amigos míos, es un lugar que suelo frecuentar y que me gusta mucho. Por eso he pensado crear esta landing page de prueba, utilizando un concepto de "scroll animation" para crear una pagina diferente la las comunes.

## ¿QUE HACE DE ESPECIAL?

Utiliza un scroll virtual y el tamaño de la pantalla para crear unas animaciones sincronizadas con el scroll (incluyendo el táctil), haciendo el recorrido de la pagina a una vista a la vez (del alto de la pantalla), cada una con una animación diferente.

Utiliza GSAP para realizar las animaciones.

## IMPORTANTE!!!

Esta landing page es una prueba de concepto, no es un sitio oficial de TSJ.
